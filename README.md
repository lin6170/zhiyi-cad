# 制衣 CAD · 纸样工作台

在浏览器本地打开、查看和编辑服装纸样的实验性 CAD。

**在线使用：[GitHub Pages](https://lin6170.github.io/zhiyi-cad/?v=40)**

## v40：ET v5 独立直线回存

已支持验证过的单尺码 v5 PRJ：修改一条符合条件的独立直线的一个端点，或新增普通独立直线。顶部“保存 PRJ”会显示当前可用方式及无法保存的具体原因。

- 修改端点：直接打开 PRJ → 工程信息中选择可回存的独立线 → 选择并定位 → 节点工具修改一个端点 → 保存 PRJ → 预览并下载。
- 新增直线：直接打开 PRJ → 用“直线”工具绘制 → 结束绘制并切回“选择” → 保存 PRJ → 预览新增直线 → 下载副本。
- 两种修改目前分别回存；需要连续使用时，先下载 PRJ，再打开该副本进行下一步。新线不自动加入裁片。
- “保存工程”下载 `.zycad`，保留全部网页编辑。PRJ 下载不覆盖原文件，也不清除工程未保存状态。

原始 PRJ 字节只保留在直接导入的当前会话中；从 `.zycad` 或恢复记录打开后，需要重新导入 PRJ 才能回存。

## 实际验收

v40 网页实际修改端点并新增两条直线，然后通过 Windows 原生自动化，在用户提供的 ET 2017 安装中打开、继续绘图、另存、重开，再次保存并重开。保存文件中的 425 条原曲线记录、962 个原节点、80 条独立标注逐字节保留；19 个裁片关联和 38 条裁片标签保留。ET 新增的两点连续线已写入。ET 保存文件也能回到网页打开并继续新增直线、下载 PRJ。

此验收覆盖指定样本和受限直线操作，不代表所有 PRJ 或完整 ET 功能兼容。先前从旧格式转换到 v5 的样本中，ET 自身保存会改变部分颜色和标志；独立无修改对照已确认该现象。不能把几何一致解释为全部工艺语义已恢复。

## 当前限制

v5 只开放上述独立直线写入。曲线、连续线修改、共享节点、裁片轮廓、整片移动、删除、混合编辑及 v5 标注修改尚不支持 PRJ 回存，请保存 `.zycad`。端点与其他记录重合、未知节点扩展或不支持的文件布局会拒绝写入。新增线要求文件中存在已识别的普通独立直线模板。部分未验证的末块长度也会拒绝导出，可调整新增线数量后重试。

已验证的另一种 PRJ 布局仍支持等字节 ASCII 标注（例如 42 → 43）、独立端点和新增独立直线。中文或变长文字尚不支持原格式回存。文字和尺寸表直接来自文件字节，不使用 OCR；改表内数字不会自动改变纸样。

网页还提供节点、曲线、修剪、延伸、缝份、刀口、对缝、放码、排料和出图等工具。这些工具的工程编辑能力不等于 ET PRJ 已支持相应写入。物理单位未确认的文件，坐标不能直接当作毫米。

## 出图与部署

出图预览默认显示第一张纸样页；“查看校准页”只显示 100 mm 校准框。“完整纸样 SVG”导出全部纸样，“当前纸样页 SVG”只导出当前页。打印使用实际大小或 100%，先量校准页两方向。

这是纯静态站点，可直接部署到 GitHub Pages 的 main 分支根目录；不依赖后端，文件在浏览器本地处理。本仓库只发布网站代码，不包含用户纸样、测试文件或 ET 软件。
