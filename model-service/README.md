# 智衣 CAD 模型服务（参考实现）

网页里的“制版助手”有两种理解方式：

- **本机指令**：不联网，只认识固定的说法。
- **模型服务**：把你说的话交给一个大模型，由它规划画图步骤。

这个文件夹就是第二种方式要用的服务。它在你自己的电脑上运行，模型密钥只放在这里，网页拿不到。

**现状说明。** 这个服务的每一部分都用“假的模型”测试过（收发格式、计划检查、纠错、出错提示、网页联调）。还没有用真的大模型跑过，因为这需要你的密钥。第一次接上模型后，请先运行下面的“自检”。

## 它做什么

1. 网页把三样东西发给它：你说的那句话、画布的描述（裁片和线条的名称、尺寸、位置）、命令目录（网页能执行的全部命令）。
2. 它请模型给出一份计划：按顺序执行哪些命令。
3. 它按命令目录检查这份计划。不合格就把原因告诉模型，让模型改，最多改两次。
4. 合格的计划发回网页。网页先预演给你看，你点“应用”后才改图。预演失败时，网页会把原因发回来，让模型再改。

模型只能提议命令目录里的命令，不能直接改你的图。

## 需要什么

- [Node.js](https://nodejs.org/) 20 或更新的版本。
- 一个大模型的密钥（演示模式不需要）。

## 先试连通（不需要密钥）

在这个文件夹里打开命令行，运行：

```
node server.mjs --provider demo
```

Windows 上也可以双击 `start-demo.cmd`。看到“服务地址：http://127.0.0.1:8787”后：

1. 打开智衣 CAD 网页，点“AI 助手”，再点助手面板里的“设置”。
2. 选“模型服务”，服务地址填 `http://127.0.0.1:8787`，点“测试连接”。显示“已连接。这个服务是演示模式”就对了。
3. 点“保存设置”，然后对助手说：`画一个 20x10 的矩形`。

演示模式只认识这一句话，用来确认网页和服务之间是通的。浏览器第一次连接本机服务时，可能会问是否允许这个网站访问本机网络，请选“允许”。

## 接上 Claude

1. 在这个文件夹里运行一次 `npm install`（安装 Anthropic 官方 SDK）。
2. 把 `.env.example` 复制一份，改名为 `.env`，在 `ANTHROPIC_API_KEY=` 后面填上你的密钥。
3. 运行自检：`node server.mjs --check`。它会请模型画一条 10 厘米的水平线，打印模型的回答。显示“自检通过”就可以用了。
4. 启动：`node server.mjs`（Windows 上可以双击 `start.cmd`）。
5. 在网页的助手设置里选“模型服务”，填服务地址，点“测试连接”，再点“保存设置”。

默认模型是 `claude-opus-5-5`。要换模型，在 `.env` 里加一行 `ANTHROPIC_MODEL=模型名`。

## 接上别的模型

很多模型服务提供“OpenAI 兼容接口”（chat completions，并且支持 function calling / 工具调用）。在 `.env` 里这样写：

```
MODEL_PROVIDER=openai-compatible
MODEL_BASE_URL=https://服务商给的接口地址/v1
MODEL_NAME=模型名称
MODEL_API_KEY=你的密钥
```

然后同样先运行 `node server.mjs --check`。这种方式不需要 `npm install`，需要 Node.js 18 或更新的版本。模型必须支持工具调用，否则自检会失败。

想接其他接口，可以照 `providers/` 里的文件再写一个：它只需要实现“发一段提示词，拿回一次工具调用或一段文字”。

## 给别的电脑用

默认只有这台电脑上的网页能连它。要让车间里别的电脑用，需要：

- 设置 `HOST=0.0.0.0`，并且必须设置 `ACCESS_CODE`（至少 8 个字符）。使用的人在网页的助手设置里填同一个访问码。
- 网页是 https 的，所以服务也要有 https 地址（在前面放一个带证书的反向代理），并把这个域名写进 `PUBLIC_HOSTS`。
- 如果网页不是从 `https://lin6170.github.io` 打开的，把网页的网址写进 `ALLOWED_ORIGINS`。

## 全部设置

写在 `.env` 里，或者设成环境变量。

| 名称 | 默认 | 说明 |
|---|---|---|
| `MODEL_PROVIDER` | `anthropic` | `anthropic`、`openai-compatible` 或 `demo` |
| `ANTHROPIC_API_KEY` | | Claude 的密钥 |
| `ANTHROPIC_MODEL` | `claude-opus-5-5` | Claude 的模型名 |
| `ANTHROPIC_EFFORT` | 模型默认 | 思考深度：`low`、`medium`、`high`、`xhigh`、`max` |
| `MODEL_BASE_URL`、`MODEL_NAME`、`MODEL_API_KEY` | | 兼容接口的地址、模型名、密钥 |
| `MODEL_TOOL_CHOICE` | `auto` | 兼容接口怎样要求工具调用：`auto`、`required`、`function` |
| `MODEL_MAX_TOKENS` | Claude 为 16000 | 一次回答的长度上限 |
| `PORT` | `8787` | 端口 |
| `HOST` | `127.0.0.1` | 只对本机开放。改成别的地址时必须设 `ACCESS_CODE` |
| `ALLOWED_ORIGINS` | 正式网页和本机测试地址 | 允许哪些网页调用，用逗号分开 |
| `PUBLIC_HOSTS` | | 通过域名访问时，允许的域名，用逗号分开 |
| `ACCESS_CODE` | 不设 | 访问码 |
| `RATE_PER_MINUTE` | `20` | 每分钟最多处理几条指令 |
| `MAX_CONCURRENT` | `2` | 同时最多处理几条 |
| `DEADLINE_MS` | `80000` | 一条指令最多等模型多久（毫秒）。网页最多等 90 秒 |
| `MAX_REPAIRS` | `2` | 计划不合格时，最多让模型改几次 |
| `MAX_BODY_BYTES` | `2000000` | 一次请求的大小上限 |

## 发出去的内容

- 发给模型的：你对助手说的话、最近几句对话、画布描述（裁片和线条的名称、尺寸、坐标，画布上的文字）、命令目录。纸样文件本身不发送。
- 服务的窗口里每条指令只记一行：时间、结果、用时、步骤数、用了多少 token。不记你说的话，不记画布内容，不记密钥和访问码。
- 密钥只在 `.env` 或环境变量里。`.env` 不要发给别人，也不要上传。

每条指令都会把命令目录（十万个字符左右）和画布描述发给模型，按模型服务商的标准计费。用 Claude 时，命令目录这一段启用了缓存，连续使用时这一段按缓存价计费。

## 常见问题

| 现象 | 原因和办法 |
|---|---|
| 网页说“连不上模型服务” | 服务没有启动，或地址填错。地址是 `http://127.0.0.1:8787`，后面不要加别的。浏览器问是否允许访问本机网络时要选“允许” |
| “这个服务没有允许来自 … 的页面” | 网页的网址不在 `ALLOWED_ORIGINS` 里。把提示里的网址加进去，重新启动服务 |
| “访问码不对” | 网页里填的访问码和 `ACCESS_CODE` 不一样 |
| “模型密钥无效或没有权限” | `.env` 里的密钥不对，或账户没有这个模型的权限 |
| “模型接口正忙或额度已用完” | 稍后再试，或检查账户余额 |
| “模型在限定时间内没有答完” | 这句话太复杂或网络慢。分成几句说，或把 `DEADLINE_MS` 调大（不要超过 85000） |
| “模型给出的计划不符合命令目录” | 模型连续几次给出不合格的计划。换一种说法，或换更强的模型 |
| 启动时说“端口已被占用” | 上一次的服务还开着，关掉它；或在 `.env` 里用 `PORT` 换一个端口 |

## 给开发者

- 协议：`POST /v1/plan`，请求和回答的格式写在网页的 `assistant-remote.mjs` 文件开头；`GET /v1/health` 用于“测试连接”。
- `lib/planner.mjs`：检查请求、拼提示词、检查计划、纠错循环。与具体模型无关。
- `lib/schema.mjs`：按命令的参数定义检查参数。
- `providers/anthropic.mjs`：Claude，使用官方 SDK，流式请求，命令目录部分做了提示词缓存。
- `providers/openai-compatible.mjs`：兼容接口。
- `providers/demo.mjs`：演示模式。
- `server.mjs`：HTTP 服务。只应答允许的网页来源，检查 Host、内容类型和访问码，限流，调用方断开时停止模型请求。
