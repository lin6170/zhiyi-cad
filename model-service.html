搭建模型服务

让“AI 助手”听懂更自由的说法：把你的话交给大模型，由它规划画图步骤。

助手默认用“本机指令”，不联网，只认识固定的说法。接上模型服务以后，可以用平常说话的方式下指令。模型只能提议网页已有的画图命令，计划先预演给你看，点“应用”后才改图。

模型服务是一个要你自己运行的小程序，模型密钥只放在它那里，网页不保存密钥。这个程序已经用模拟的模型完整测试过，还没有用真的大模型跑过；第一次接上模型后请先做第 4 步的自检。

1. 下载

下载模型服务（zip）

解压到任意文件夹。另外需要安装 Node.js 20 或更新的版本。

2. 先试连通（不需要密钥）

在解压出的文件夹里双击 start-demo.cmd，或在命令行运行：

node server.mjs --provider demo

看到“服务地址：http://127.0.0.1:8787”后，回到智衣 CAD：

  1. 点“AI 助手”，再点助手面板里的“设置”。
  2. 选“模型服务”，服务地址填 http://127.0.0.1:8787，点“测试连接”。
  3. 显示“已连接”后点“保存设置”，对助手说：画一个 20x10 的矩形。

演示模式只认识这一句话，用来确认网页和服务之间是通的。浏览器询问是否允许这个网站访问本机网络时，请选“允许”。

3. 填上模型密钥

把文件夹里的 .env.example 复制一份，改名为 .env，按里面的说明填写。

  • Claude：在 ANTHROPIC_API_KEY= 后面填密钥，并在文件夹里运行一次 npm install。
  • 其他模型：只要服务商提供“OpenAI 兼容接口”并支持工具调用，就填接口地址、模型名称和密钥（MODEL_PROVIDER=openai-compatible）。

4. 自检，然后启动

node server.mjs --check

自检会请模型画一条 10 厘米的水平线，并打印模型的回答。显示“自检通过”后，双击 start.cmd 或运行 node server.mjs 启动服务，再到助手设置里点“测试连接”和“保存设置”。

会发出去什么

  • 发给模型的：你对助手说的话、最近几句对话、画布上裁片和线条的名称、尺寸、坐标和文字，以及网页的命令目录。纸样文件本身不发送。
  • 服务的窗口里每条指令只记一行结果，不记你说的话和画布内容。
  • 每条指令按模型服务商的标准计费。

遇到问题

提示办法
连不上模型服务服务没有启动，或地址填错。地址是 http://127.0.0.1:8787，后面不要加别的。浏览器询问是否允许访问本机网络时要选“允许”。
这个服务没有允许来自 … 的页面把提示里的网址加到 .env 的 ALLOWED_ORIGINS 里，重新启动服务。
模型密钥无效或没有权限检查 .env 里的密钥。
模型在限定时间内没有答完把要求分成几句来说。

更多设置（换模型、换端口、给别的电脑用、访问码）见压缩包里的 README.md。
